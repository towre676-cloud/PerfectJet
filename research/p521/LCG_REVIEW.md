# Independent review of the P-521 LCG exclusions

The review accepts the integer dual-obstruction argument and the stated Mersenne interior-window argument. It independently regenerated the public observations, validated complete certificate coverage, recompiled the native scanner, and reran all 327,680,000 compatible first-state checks in the 3,302 declared traces. No coordinate trace matched. This is a review of the implemented model and finite proofs, with no claim to a new general lattice-reduction algorithm, worldwide priority, recovery of a private key, or a complete explanation of the public base point.

For the affine recurrence \(x_{i+1}=a x_i+c\pmod {2^{48}}\), define \(d_0=0\) and \(d_{i+1}=a d_i+c\pmod {2^{48}}\). A supplied integer relation \(q\) must satisfy \(\sum_iq_i a^i=0\pmod {2^{48}}\). Every compatible hidden state therefore forces \(\sum_iq_i(x_i-d_i)\) to be a multiple of \(2^{48}\). An observed top byte \(b_i\) puts \(x_i\) in the exact integer interval \([2^{40}b_i,2^{40}(b_i+1)-1]\). Computing the extreme functional values over the product of these intervals yields a sound necessary condition. A closed interval containing no multiple of the modulus certifies that no 48-bit initial state produces the observed sequence. No LLL or CVP success or failure is trusted during verification.

All 188 twenty-byte windows of the two 66-byte public coordinates, in both byte orders, carry such proofs. The independent checker reconstructs every required window and rejects absent, duplicate, foreign, or corrupted certificates. A satisfiable control made from the published P-521 seed cannot pass an exclusion check using the same annihilating relation. The independently replayed known-seed first state is 229179504894237; the initialization lies 22,701 raw draws before it, at timestamp 871002724, and identifies candidate 1,136.

For a direct raw-byte assembly \(R\), equality \(R\bmod(2^{521}-1)=G\) implies \(R=G-q+q2^{521}\), with an explicitly bounded nonnegative quotient \(q\). Whenever \(G\bmod 2^\ell\ge q_{\max}\), subtraction cannot borrow across bit \(\ell\). A 160-bit byte-aligned window beginning there and ending below bit 521 is consequently unchanged for every admissible quotient. Each model certificate checks that condition and the associated exact output obstruction. The frozen release contract covers both coordinates, raw lengths 65 through 109 bytes, and both byte orders. The 179 proof rows cover 180 coordinate/length/order cases because the single raw-range proof for the 65-byte y-coordinate excludes both orders. Length 110 remains explicitly unresolved for both coordinates.

The native scanner's workload comprises contiguous top-31-bit traces, contiguous top-32-bit traces, and 31-bit outputs padded into 32-bit words. The top-32-bit mode is an additional hypothetical state slice; the POSIX `lrand48` API itself returns 31 bits. Padding-incompatible words are excluded before state enumeration because they cannot represent that output format. For each retained trace, the scanner enumerates every missing low-state bit and checks all subsequent observations. Unsigned 64-bit multiplication is sound here: although the full product can exceed 64 bits, retaining its low 48 bits is identical to arithmetic modulo \(2^{48}\).

The first implementation of the discovery module's receipt checker verified each supplied assembly proof but did not require complete assembly coverage. The review identified that omission; deleting all assembly rows could incorrectly preserve its summary `verified` flag. The discovery checker was strengthened, and the separate `verify_lcg_certificate.py` independently requires all 179 assembly rows, all 188 coordinate windows, precisely the declared unresolved boundary, the regenerated native query digest, and exact scan counts. Mutation tests delete proof sets, corrupt a quotient, alter a dual relation, and change a native count. Every mutation is rejected. The optional `--rerun-native` path recompiles and reruns the exhaustive native workload; without that flag the checker accurately reports that only its metadata and mathematical certificates were checked.

The exclusion scope is direct consecutive top-eight-bit bytes from the specified affine 48-bit generator, the listed assemblies, and reduction modulo the P-521 field prime. Different output slices, discarded bytes within a coordinate, hash expansion, scalar multiplication, other generators, and other raw assembly lengths require separate models. The top-bit fingerprint scan has its own narrower trace scope and does not silently extend the direct-byte theorem.

Validation performed: `python research/p521/verify_lcg_certificate.py --rerun-native` passed, reporting 188 byte-trace proofs, 179 assembly proof rows, 180 assembly cases, 3,302 native traces and 327,680,000 enumerated compatible first states. Three independent-checker tests passed, including removal/corruption controls and a satisfiable known-generator control. The independent checker imports only the Python standard library and does not import the discovery module.

The later `word_obstruction.py` result is also sound for its precise model. Seventeen unsigned 31-bit values stored as 32-bit integer slots force bit 31 of the assembled raw integer to zero, regardless of the ordering of the slots. If its reduction modulo \(2^{521}-1\) equalled either published coordinate \(G\), the raw integer would be \(G-q+q2^{521}\), with \(0\le q\le8,388,607\) from the conservative full 544-bit raw bound. Both coordinates have bit 31 equal to one, and their low 31 bits are respectively 1,122,352,486 and 533,816,912. Those low parts exceed the quotient bound, so subtracting any admissible quotient cannot borrow across bit 31. The raw bit must therefore remain one, a contradiction. The conservative bound includes every allowed word tuple, so its excess generality is harmless. This eliminates both word orders for both coordinates independently of any RNG recurrence. It does not cover reversing bytes within individual 32-bit slots.
