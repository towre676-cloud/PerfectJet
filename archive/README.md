# Archival sources and session preservation

`extracted/` preserves readable source content recovered during the two archival passes. The originals are not overwritten by the corrected master synthesis. Claims inside an archived manuscript keep their historical wording and can be stronger than the canonical evidence supports.

`SOURCES.json` gives the recovered source title, file reference, extraction scope, local path, and SHA256 of these local bytes. DOCX/PDF text extraction is not a byte-identical copy of the original document. Selected HTML sections omit embedded image payloads while retaining the mathematical text. The source index states these limitations.

The original transvectant verifier requires SymPy and is preserved for provenance. Its numerical orbit-count routine is not used as a canonical exact certificate. The canonical `src/perfectjet` core is dependency-free and its checks are separate.

`session/coverage.json` maps all five discussion passes to chapters and registries. The canonical synthesis preserves their mathematical content and corrections; it is not presented as a verbatim transcript or an exhaustive archive of every past conversation. Unrecovered originals remain listed in the monograph.
