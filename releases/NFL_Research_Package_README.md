# Complete NFL research archive

Download all three `.zip.part01`–`.zip.part03` files, `NFL_Research_Package_Parts.json`, and `restore_nfl_research_package.py` into one folder. Run `python restore_nfl_research_package.py` to reconstruct the complete ZIP. Every part and the complete archive are checked with SHA-256. The split preserves the original ZIP bytes exactly; it avoids the publishing service request-size limit. No raw competition data or private player outputs are included.
